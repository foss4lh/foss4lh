# Herefordshire Tithe Maps (hfd-tithe-maps)

## Metadata
- **Collection Start:** 1837
- **Publication Year:** 1845
- **Coverage:** Herefordshire
- **Status:** Georectified

## Description
Detailed scans of tithe maps and schedules for Herefordshire parishes. These maps provide a critical snapshot of the landscape before significant industrial and modern agricultural changes.

## Access
Data is available as `.tiff` and `.acw` files. Georeferenced layers can be explored in the Landscape Explorer.
